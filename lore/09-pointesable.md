## Nualia et le lancement possible des Sept Fléaux

Dans *Les Sept Fléaux de Pointesable*, l'ouverture est particulièrement compatible avec la continuité actuelle :

- Abstalar Zantus regrette la manière dont Pointesable et son ancien prêtre Ezakien Tobyn ont traité Nualia ;
- il souhaite contacter son esprit avec l'aide d'**Audrahni** ;
- le rituel exige un lien physique avec Nualia ;
- sa tombe est ouverte ;
- le cercueil est vide ;
- un tunnel mène sous le cimetière ;
- des goules ont volé les ossements ;
- cette enquête ouvre vers les catacombes et la Fosse.

Le rôle de Corvan peut être celui du vétéran à qui Zantus fait confiance pour recommander / envoyer la nouvelle génération de héros.
