# PF2e Val Automations

Module compagnon personnel pour compléter PF2e Automations sans modifier ses fichiers.

## 0.1.0

- Ajoute automatiquement une règle custom pour **Spray of Stars / Aspersion d'étoiles** si PF2e Automations ne la gère pas déjà.
- Retire automatiquement cette règle custom si une future version de PF2e Automations couvre officiellement le sort.
- Aucun handler JS complexe dans cette première version.
